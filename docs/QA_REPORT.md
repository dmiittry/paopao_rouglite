Начальные таблицы целей из ТЗ сохранены; поздний баланс требует игровых плейтестов.

## Поставка и ограничения

Финальная сборка открыта отдельно на `http://127.0.0.1:4174`, с чистым origin и без тестовых рекордов с порта 4173. Предварительный сервер тестов остановлен; сервер финальной сборки запущен отдельно в фоне. Повторный локальный запуск — `START_GAME.bat`, обычно порт 4173, следующий свободный при конфликте.
