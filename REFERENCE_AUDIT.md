Из реестра изучены категории очков, аддитивных/мультипликативных бонусов, экономики, повторных эффектов, манипуляции колодой, накопления и сочетаний предметов. Эти общие технические принципы реализованы заново. Balatropedia — справочник; игровой цикл, поле Onet, пути и боссы этого проекта написаны самостоятельно.

Код референса загружался только во временный каталог для чтения. Исходные файлы референса, массивы его контента и медиа не включены в проект или dist.

## Лицензионное решение

В package.json Balatropedia есть декларация `license: MIT`. При этом GitHub API не вернул распознанную лицензию репозитория; отдельного LICENSE/COPYING в просмотренном дереве не найдено. README описывает некоммерческий фанатский проект, использующий чужие названия/изображения для справочных целей. Одна декларация package.json не подтверждает права на все включённые материалы.

Поэтому **код не копировался**, даже из потенциально MIT-части. Не использованы имена и описания джокеров Balatro, их спрайты, музыка, файлы SFX, таблицы очков из референса, иллюстрации, шрифты и другие защищённые материалы. Наличие доступного исходного текста не трактуется как лицензия на чужие игровые ресурсы.

## Наши зависимости и ресурсы

| Компонент | Статус |
| --- | --- |
| HTML/CSS/ES modules, Canvas, Web Animations, Web Audio | Стандартные браузерные API, сторонний код не включается |
| Графика карт, эмблемы джокеров, фон, сундуки | Созданы в проекте средствами CSS и SVG-примитивов; нет скачанных изображений |
| Звук и музыкальный фон | Созданы программно; нет музыкальных/звуковых файлов из внешних источников |
| Шрифты | Системные Arial/Segoe UI/Georgia; файлы шрифтов не поставляются |
| Runtime-зависимости игры | **Отсутствуют**, package.json не содержит dependencies или devDependencies |
| Node.js | Используется как установленный инструмент разработки/локального запуска. Его бинарники не включены в дистрибутив |
| Prettier 3.6.2 | MIT, текст LICENSE просмотрен. Использован только из временного каталога для форматирования; в проект/dist не включён |
| Зависимости Balatropedia (React, UI-библиотеки, сервер и др.) | Не использованы. Их лицензии не объявляются проверенными/разрешёнными для будущего переноса |

Проект не вводит автоматически open-source лицензию на код пользователя. Выбор условий распространения собственной игры остаётся за владельцем. Перед коммерческим выпуском отдельно проверяются торговая марка/финальное название и лицензии любых ресурсов, которые будут добавлены позднее.
