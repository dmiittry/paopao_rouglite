### Важные детали для следующих изменений
- Сначала Game.transact полностью меняет/проверяет/сохраняет модель, затем UI проигрывает события. Не переносить начисления в callbacks анимации.
- Пути выбираются по минимуму поворотов, потом длине; fallback перемешивания сохраняет занятые позиции и переставляет существующую пару в геометрически соединяемые клетки.
- Карточные улучшения — map по текущей идентичности, до 3 свойств; стекло/проклятие несовместимы.
- Трансформацию живой исходной пары из одной оставшейся плитки запрещаем, чтобы не создавать нечётные идентичности.
- Эхо: overflow хранится до следующего сбора, резерв максимум 3, в конце этапа 15 очков за карту. Доход при сборе платится за соединение, при scoring — за каждую эхо-карту.
- Подписки событий имеют source/event ID и ограничение глубины. Copyist копирует левого соседа только в scoring, не копировщика; накопление Eternal не увеличивается повторно.
- Save schema 1; origin-specific localStorage. Ошибки сохранения выводятся пользователю.
- Debug скрыт без ?debug=1; включение создаёт window.labyrinth.
