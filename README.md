# Лабиринт Джокера

**Joker's Labyrinth: Card Connect** — одиночный браузерный Onet + poker roguelite. Вы сами добываете карты из пространственного поля, улучшаете колоду и проходите главы с боссами.

## Запуск

На Windows дважды нажмите **START_GAME.bat**. Он найдёт Node.js (включая встроенный runtime Codex), запустит локальный сервер в фоне и откроет игру. Установка npm-пакетов не нужна.

Альтернативно, из папки проекта:

```sh
node scripts/serve.mjs
```

Откройте **http://127.0.0.1:4173**. Нужен Node.js 20+ и современный браузер. Не открывайте `index.html` через `file://`: ES-модулям нужен HTTP.

```sh
node --test tests/*.test.js   # автоматические тесты
node scripts/simulate.mjs 40 # балансировочный бот
node scripts/build.mjs      # статическая сборка dist/
node scripts/serve.mjs --dist
```

Содержимое `dist/` можно разместить на обычном статическом хостинге, в том числе в подкаталоге. Backend, внешние шрифты, сетевые игровые сервисы и сторонние runtime-библиотеки не нужны. Веб-публикация и Steam-упаковка в эту локальную поставку не входят.

## Управление

| Действие | Управление |
| --- | --- |
| Собрать пару | Левый клик по двум одинаковым картам |
| Уничтожить пару | Правый клик по двум одинаковым картам; карта в руку не поступает |
| Сенсорное управление | Переключатель «Собрать / Уничтожить» |
| Перемешать | Кнопка или S |
| Сменить режим | B |
| Подсказка | Кнопка или H, бесплатно показывает одну пару |
| Клавиатурный выбор | Стрелки и Enter/Space |
| Пауза | Esc |
| Ночной Джокер | Перемещайте курсор / палец по полю; клавиатурный фокус также двигает свет |

Соединение проходит по пустым клеткам с максимум **2 поворотами**, включая внешнюю границу. Джокеры, босс и ритуалы могут менять лимит от 1 до 4. Выбирается маршрут с наименьшим числом поворотов, затем с наименьшей длиной.

Пять добытых карт автоматически разыгрываются. Обычно доступно четыре руки на этап, два уничтожения и два ручных перемешивания. Нет таймера. При отсутствии доступных пар оставшиеся плитки бесплатно перемешиваются с гарантированным ходом.

## Что реализовано

- Фиксированное поле **13 × 8**, 52 исходные пары, всегда 104 плитки в начале этапа.
- Независимые свойства покерной руки: сильнейшее повторение рангов + стрит + флеш + отдельные синергии. Пять одинаковых, каре с флешем и фулл-хаус с флешем работают.
- Формула `floor(chips × mult × xMult)`. Полная история расчёта доступна справа.
- **34 джокера**, **14 улучшений**, **12 ритуалов**, **12 стартовых усилений**, **20 движений**, **8 боссов**, **12 достижений**, **6 контрактов**, **3 случайные встречи**, **4 класса сундуков**.
- Магазин: покупка/продажа, рероллы, выбор идентичностей для улучшения, преобразование исходных пар, дополнительные слоты и уровни комбинаций.
- Каждая третья комната — босс; после главы можно продолжить или завершить забег. После восьмого этапа цель растёт ×1,48 на этап; награда растёт умеренно.
- Анимации Web Animations API, Canvas-частицы, собственный синтез звука и тихий музыкальный фон Web Audio.
- Меню, коллекция с закрытым контентом, достижения, настройки, адаптация под узкий экран, клавиатура.
- Версионированное автосохранение точного поля, руки, резерва, RNG, ресурсов, магазина и результатов. Покупки и награды защищены от повторного начисления.

## Правила эффектов

**Эхо ×2:** одна пара выдаёт две карты. «Двойное сердце» увеличивает это число до трёх. Излишек идёт в резерв максимум на 3 карты. Резерв поступает в руку при следующем сборе. На завершении этапа каждая резервная карта превращается в 15 очков; переполнение также даёт 15. Коллекционные денежные эффекты срабатывают один раз на соединение, а эффекты розыгрыша — на каждую карту, включая Эхо.

**Улучшения:** до трёх свойств на текущую идентичность `rank+suit`. Все одинаковые плитки имеют одинаковые свойства. Стеклянная и Проклятая несовместимы. Стеклянная может уснуть до следующего этапа — она не удаляет физические плитки. Двойная масть использует цикл ♥ → ♠ → ♣ → ♦ → ♥.

**Преобразования:** меняют одну из 52 исходных пар. При переходе в новую идентичность используются свойства новой идентичности. Если в текущем поле от исходной пары осталась одна плитка после соединения с другой исходной парой, её нельзя преобразовать ритуалом до следующего этапа: это сохраняет чётность.

**Порядок:** очки комбинации → независимые комбинации → номиналы → геометрия → улучшения → эффекты карт → эффекты руки → аддитивные множители → произведение усилений → босс. У каждого вклада свой ID. Джокеры независимы от порядка слотов, кроме «Левого летописца»: он копирует соседний слева очковый эффект, не копируя копировщиков.

**Синергии:** Архитектор + Обходчик дают +80 при внешнем маршруте с двумя поворотами. Алый барон + Хозяин флеша дают дополнительное ×1,3 для флеша из червей. Мастер кузницы улучшает до трёх выбранных идентичностей за одну покупку; Атлас мастей расширяет выбор до десяти.

## Сохранение и архитектура

Ключ localStorage — `jokers-labyrinth.v1`. Сохранение содержит единый документ версии 1: забег, метапрогресс и настройки. Вся игровая транзакция завершается и сохраняется **до анимации**. Перезагрузка во время подсчёта не повторяет награду. Неподдерживаемые и повреждённые сохранения отклоняются с сообщением. При недоступном хранилище игра предупреждает, что запись не удалась. Сохранения привязаны к браузеру и origin (адресу/порту).

- `src/core/` — Game: переходы и транзакции; RNG; EventBus; SaveManager.
- `src/board/` — детерминированный поиск, перемешивание с геометрическим fallback, движения.
- `src/cards/` — blueprint-колода, evaluator, score timeline.
- `src/roguelite/EffectEngine.js` — реальная обработка эффектов, правила и ограничения.
- `src/data/` — каталоги, редкости, цены, условия открытий.
- `src/ui/` — отображение и отдельные адаптеры звука/анимации/частиц.
- `src/config.js` — параметры поля, очков, экономики, Эхо и резерва.
- `tests/` — unit, regression и детерминированное прохождение забега без debug.

События упорядочены по source ID; защищены от повторной обработки и глубины рекурсии свыше 8. Все игровые случайности используют сохранённый RNG. `Math.random()` используется только для декоративных частиц.

Для отладки откройте `http://127.0.0.1:4173/?debug=1`. Справа появится панель выдачи золота/джокеров/улучшений, выбора босса/движения и числа рук. Там же доступен `window.labyrinth`. В обычном URL отладочная панель и глобальный объект не создаются.
